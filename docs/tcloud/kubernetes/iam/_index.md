## tcloud kubernetes iam

Kubernetes cluster IAM roles and bindings

### Synopsis

Manage Kubernetes cluster IAM roles, permission rules, and role bindings.
These roles control access within your organisation's Kubernetes clusters on Thalassa Cloud.
